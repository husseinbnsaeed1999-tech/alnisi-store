ALNiSi Online Store Starter

هذه حزمة جاهزة كبداية للموقع الأونلاين.
- index.html: واجهة المتجر ولوحة الإدارة التجريبية.
- database.sql: جداول قاعدة البيانات المقترحة.

مهم:
النسخة الموجودة هنا تعمل محلياً في هذه اللحظة حتى يتم ربطها باستضافة وقاعدة بيانات.
لا تضع مفاتيح قاعدة البيانات السرية داخل index.html.

بعد إنشاء الاستضافة وقاعدة البيانات، يتم ربط:
1. المنتجات.
2. صور المنتجات (Storage).
3. لوحة الإدارة وتسجيل الدخول.
4. واتساب.
5. طرق الدفع.
6. الطلبات وحالات الدفع.
